# Titre du menu Rusted

`rusted-title.png` est la version à fond transparent du visuel demandé et fourni
par le propriétaire du projet : logo Minecraft avec sous-titre cuivré
« RUSTED EDITION ». La transparence a été préparée à partir de cette référence.

Ce visuel n'est pas une création du projet Horizon et n'est pas couvert par sa
licence MIT. Les marques et éléments graphiques Minecraft restent ceux de leurs
titulaires. Aucun fichier du jeu Minecraft n'a été extrait pour créer cet asset.

Le PNG est distribué dans `runtime/rusted-title.png`. Le moteur le charge à côté
de son exécutable, retire sa marge transparente au placement et conserve ses
proportions. Le titre classique reste disponible si le fichier est absent ou
invalide. `RUSTED_TITLE_LOGO` peut désigner un autre PNG pour les essais locaux.
