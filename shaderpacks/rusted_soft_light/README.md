# Rusted Soft Light

Original optional native WGSL post-processing pack. Adds restrained warmth and saturation.
No shadow pass, bloom, water effects, Java mod or Iris shader-pack compatibility.
The manifest and stage use the documented native API inherited from Horizon.
The shader code is original Rusted code; no shader/mod source was downloaded or copied.

Install the .hshader in the native data folder's shaderpacks directory and select it
in the game's native Shader Packs settings. Off by default. HUD colours are unchanged.
