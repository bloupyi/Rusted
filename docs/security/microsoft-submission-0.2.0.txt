The application is an unsigned original Rust/Win32 Minecraft launcher, cross-compiled
with the x86_64-pc-windows-gnu toolchain. It downloads hash-verified Minecraft resources
and a Java runtime from their providers. On first startup it begins preparation of a
native client in a user data folder. Preparation and game processes are launched as
owned child processes; Windows Job Objects stop those children when the launcher closes.
Console windows are suppressed for child programs, with their output shown in the GUI.
Optional Microsoft device authentication uses a project-specific public client id;
account tokens are protected with current-user DPAPI. This release contains no client id.
